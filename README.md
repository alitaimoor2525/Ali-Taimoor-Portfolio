## 🚀 Running it locally

```sh
git clone https://github.com/alitaimoor2525/Ali-Taimoor-Portfolio.git
cd Ali-Taimoor-Portfolio
npm install
npm run dev
```

The site will be running at `http://localhost:3000`.
